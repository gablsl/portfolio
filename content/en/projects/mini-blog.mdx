In this project, all the necessary routes for navigation were developed, as well as the header and footer components across all pages, including post details. Props were used for efficient data passing between components. Hooks such as useState and useEffect were essential for managing state and side effects, and custom hooks were created for specific features. Axios integration was key for making efficient and asynchronous HTTP requests, ensuring a smooth user experience.
