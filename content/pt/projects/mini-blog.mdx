Neste projeto, foram desenvolvidas todas as rotas necessárias para a navegação, bem como a componentização do cabeçalho e rodapé em todas as páginas, incluindo os detalhes dos posts. Além disso, utilizou-se props para a transmissão eficiente de dados entre os diversos componentes. A implementação dos hooks, como useState e useEffect, foi essencial para a gestão do estado e dos efeitos secundários na aplicação. Também foram criados hooks personalizados para funcionalidades específicas. A integração com o axios foi fundamental para realizar requisições HTTP de forma eficiente e assíncrona, garantindo uma experiência fluida aos usuários.
