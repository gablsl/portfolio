World Trip é um projeto de site de viagens desenvolvido com Next.js e Chakra UI. Com uma interface intuitiva e elegante, os usuários podem explorar destinos ao redor do mundo, encontrar as melhores ofertas em passagens e hospedagens, além de descobrir experiências únicas para tornar suas viagens inesquecíveis. Este projeto demonstra como tecnologias modernas como Next.js e Chakra UI podem ser combinadas para criar uma experiência de usuário atraente e responsiva
